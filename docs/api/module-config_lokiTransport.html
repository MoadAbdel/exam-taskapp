Module: config/lokiTransport

Transport Winston vers Grafana Loki (Grafana Cloud). Les logs sont mis en file puis envoyes par lots a l'API POST /loki/api/v1/push.

  • Sur Vercel : envoi apres chaque reponse via waitUntil (aucune attente pour l'utilisateur).
  • Ailleurs (Docker, local) : envoi toutes les 5 secondes. Etiquettes Loki volontairement peu nombreuses (service, env, level) ; le detail reste dans la ligne JSON. Une panne de Loki ne bloque jamais l'application : le lot est abandonne et l'erreur affichee sur stderr.
