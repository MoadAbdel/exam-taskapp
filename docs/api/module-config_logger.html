Module: config/logger

Journalisation structuree (JSON) avec Winston.

  • Toujours sur la sortie standard : Vercel et Docker collectent ce flux.
  • En plus dans logs/error.log et logs/combined.log si LOG_TO_FILE=true (environnement Docker de preproduction, avec rotation par taille).
  • En plus vers Grafana Loki si LOKI_URL est defini (preproduction et production sur Vercel) : historique, recherche, tableaux de bord et alertes dans Grafana Cloud.
