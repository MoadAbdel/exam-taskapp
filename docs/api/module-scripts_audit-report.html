Module: scripts/audit-report

Outil d'audit : analyse la piste d'audit (collection auditlogs) d'un environnement.

Usage : MONGO_URI=... node scripts/audit-report.js [--days=7] [--fail-on-alert] (ou npm run audit:report) Sortie : rapport Markdown (evenements par type, IP suspectes, dernieres erreurs avec requestId). Code de sortie 2 avec --fail-on-alert si un seuil de securite est depasse.
