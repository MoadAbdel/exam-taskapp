Module: config/audit

Enregistre un evenement d'audit a deux endroits :

  1. le journal Winston (flux temps reel, logs Vercel / Docker) ;
  2. la collection MongoDB auditlogs (historique de 90 jours, interrogeable). Une panne de la base ne bloque jamais la requete : l'evenement reste dans le journal.
